# 🎨 CSS

CSS = Styling and layout of a webpage.

## Ways to Apply CSS

1. Inline CSS
2. Internal CSS
3. External CSS

## Selectors

Element selector
Class selector
ID selector

## Box Model

Every element can be understood as:

Content
↓
Padding
↓
Border
↓
Margin

Content → Actual content
Padding → Space inside the border
Border → Boundary around the element
Margin → Space outside the element

## Display

block → Starts on a new line

inline → Remains in the same line

inline-block → Remains in the same line while allowing width/height

# 🌳 DOM

DOM = Document Object Model.

It allows JavaScript to interact with HTML elements.

## Selecting Elements

getElementById()
→ Select an element using its ID.

querySelector()
→ Select an element using a CSS selector.

## Creating Elements

createElement()
→ Creates a new HTML element.

setAttribute()
→ Adds/changes an attribute.

append()
→ Adds an element inside another element.

## Changing Content

textContent
→ Changes the text inside an element.

## Changing Style

element.style.property
→ Changes CSS using JavaScript.

# 🖱️ Events

Events allow JavaScript to respond to user actions.

Examples:

click
mouseover

addEventListener()
→ Connects an event with a function.

Example:

button.addEventListener("click", function() {
    // action
});
